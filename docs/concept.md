# RDE Concept

Resonant Deviation Evaluator (RDE) is a framework for auditing meaning change between a source context and a generated output.

RDE does not replace factuality evaluators, safety filters, policy filters, or generic LLM-as-a-judge pipelines. It focuses on the acceptability of meaning transformation.

## Operational Delta-M

In this scaffold, meaning change (Delta-M) is operationalized through observable changes in:

- claim strength
- uncertainty and caveats
- intent
- responsibility structure
- value structure
- institutional implication
- context affinity

## Labels

- Preserved
- Authorized Transformation
- Inferred Extension
- Unresolved Gap
- Suspicious Drift
- Critical Distortion

## Status

This repository is an experimental scaffold for pilot studies. It is not a validated benchmark and not a production RDE engine.
